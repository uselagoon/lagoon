## Release Notes

This release introduces a major refactor of the webhook handling service, improves project cloning permissions and deploy target security, updates several core platform dependencies, and resolves a number of stability issues across the API and supporting services.

This release was superseded, and release [2.33.1](./2.33.1.md) is recommended to be installed instead.

### Lagoon Core

#### Webhook Handler

This release sees a substantial rewrite of the `webhook-handler` and the removal of `webhooks2tasks`. Both services have been integrated into the `webhook-handler`.
