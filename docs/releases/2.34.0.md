## Release Notes

This release adds environment volume & service state, upgrades Keycloak and other core dependencies. This release also introduces initial support for Traefik, with further guidance on usage to come.

### Lagoon Core

This release refactors webhooks & notifications, fixing a number of edgecases introduced by previous updates. It also adds new visibility into [environment volumes and service state](https://github.com/uselagoon/lagoon/pull/4065), as well as an upgrade to Keycloak 26.7.2.

### Lagoon Remote

#### Traefik Support

This release adds [initial support for Traefik](https://github.com/uselagoon/build-deploy-tool/pull/472). This is an early iteration with further guidance on usage to come.
